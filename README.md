# Graph GUI Project

Кроссплатформенное десктопное приложение на Python для построения графов, поиска кратчайших путей и визуализации результатов. Разрабатывается в рамках курса ТППО.

## Технологический стек
* **Язык:** Python 3
* **Графический интерфейс (GUI):** PySide6
* **Работа с графами и алгоритмы:** NetworkX (Дейкстра, BFS)
* **Визуализация:** Matplotlib
* **Тестирование:** Pytest
* **Автоматизация сборки:** GNU Make

## Архитектура проекта
Приложение построено по модульному принципу с разделением интерфейса и бизнес-логики:
* `src/ui/` — слой графического интерфейса (вкладки «Новичок», «Стандартный», «Профи»).
* `src/core/` — ядро приложения (`GraphManager`, вызовы алгоритмов NetworkX, подсистема обработки ошибок).
* `src/config/` — конфигурация и настройки приложения.
* `tests/` — модульные и интеграционные тесты (`pytest`).

## Быстрый старт (через Makefile)

1. **Установка зависимостей и создание виртуального окружения:**
   ```bash
   make install
   ```

2. **Запуск приложения:**
   ```bash
   make run
   ```

3. **Запуск автотестов:**
   ```bash
   make test
   ```

4. **Очистка временных файлов:**
   ```bash
   make clean
   ```
